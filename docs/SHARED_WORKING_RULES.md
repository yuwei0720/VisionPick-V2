# 兩台電腦共用的修改與寫作規則

更新：2026-11-06。這是本機報告規則的共用摘要，隨程式倉庫同步，供實機電腦與其他 AI 讀取。使用者後續明確指示優先。

## 程式修改

- 先讀相關原始碼，以必要的最小改動處理需求；每次僅改一個函式、類別或單一邏輯單元。
- 保留無關程式、設定、資料及既有介面，不主動重構、擴大功能或引入新框架。涉及設計調整時先提出方案及影響，依使用者確認的範圍進行。
- 修改前保存版本，修改後執行受影響範圍的檢查，回報實際結果與待辦；依 [AGENTS.md](../AGENTS.md) 執行。

## Word 文字

- 使用繁體中文，文字自然流暢、便於口頭表達，能直接在專題口試講清楚。主詞、動作與前後關係清楚，避免術語堆疊、翻譯腔及冗長抽象句，保留自然的學術語氣。
- 不主動添加防禦性說明、免責補丁或未被要求的反覆限制語句，不自行加回使用者已刪除的防禦句。
- 以實際方法、資料範圍、測試條件與觀察結果直接敘述；數字與結論須對應來源及版本。
- 使用者提供或已確認的段落，只在指定範圍修改；不自行重寫整段。沿用指定基準 Word 的章節、字型、行距、頁面與圖表格式，另存修訂並保留原檔。

## Word／PPT 順序與資料位置

- 實機驗收進行中，依實際情況及使用者要求持續修訂 Word；只有使用者明確確認 Word 定稿後，才開始製作或同步 PPT。
- 目前 Word 尚未經使用者確認定稿，PPT 暫緩；實機測試通過或 AI 完稿不等於使用者已確認 Word。
- Word、完整材料與格式規則由原電腦外層工作區管理：AI-HANDOFF.md、專題報告材料/AI-HANDOFF.md、專題報告材料/00_目前報告/WRITING_RULES.md；它們不在這份 Git 倉庫內。
- 克隆本倉庫可取得本共用摘要、程式交接及測試範本，不會取得 Word 本文或完整報告材料。需要在其他電腦修訂 Word 時另行移交材料並核對版本。
- 實機測試摘要、原始證據與分母依 [雙電腦流程](TWO_PC_WORKFLOW.md)保存及回傳；原電腦依已確認的結果修訂報告。
